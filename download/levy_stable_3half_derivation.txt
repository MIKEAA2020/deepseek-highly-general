TASK 2: DERIVATION OF 3/2 FATIGUE EXPONENT FROM LEVY ALPHA-STABLE
       FIRST-PASSAGE MODEL (closes Conjecture 4)
==============================================================================

Setup: loop gamma_a(t) = (a*cos(2*pi*t), a*sin(2*pi*t)) perturbed by 2D
Brownian motion W_t (variance rate sigma^2 = nu * a, with nu = 0.5).
Holonomy H = (1/2) oint (x dy - y dx), expanded in sigma.

Theoretical prediction: leading non-analytic correction std(delta_H) ~
    (sigma * a / 2) = (sqrt(nu*a) * a / 2) = (sqrt(nu)/2) * a^(3/2)
    = sqrt(0.5)/2 * a^(3/2) = 0.3536 * a^(3/2)

Sub-leading (Levy area) correction std ~ (sigma^2 / 2) * (1/sqrt(12))
    = (nu*a/2) * (1/sqrt(12)) = 0.0722 * a

For a < 1 (small loops), a^(3/2) > a, so the 3/2 correction dominates.

------------------------------------------------------------------------------
Sweeping amplitude a in [0.05, 0.5] over 12 values; 5000 seeds per amplitude
------------------------------------------------------------------------------

Log-log linear fit:  std(delta_H) = C * a^beta
  Fitted beta = 1.4789  (predicted: 3/2 = 1.5000)
  Fitted C    = 0.3566  (predicted: sqrt(nu)/2 = 0.3536)
  R^2         = 0.999919

Two-term fit:  std(delta_H) = c1*a^(3/2) + c2*a
